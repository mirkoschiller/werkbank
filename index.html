So funktioniert Werkbank

Erstelle Karten über + Karte und ziehe sie mit dem Griff in andere Spalten. Auf Touchgeräten halte den Griff und bewege den Finger. Über die Kartenmenüs kannst du Karten auch ohne Drag-and-drop verschieben.

Füge beliebig neue Spalten hinzu und benenne sie direkt um. Änderungen werden automatisch nur in diesem Browser gespeichert. Nutze ↓ JSON, um ein Backup oder eine Datei für ein anderes Gerät zu erstellen.

GitHub Pages bietet keine Live-Synchronisierung. Andere Personen sehen dein Board nicht automatisch.
